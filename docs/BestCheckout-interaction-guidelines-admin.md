# BestCheckout 后台交互通则

商家后台 (Admin) 可复用的交互与表现原则. 不含业务规则 (如 Pixel 条数、Bundle 互斥).  
编辑器见 [编辑器交互通则](./BestCheckout-interaction-guidelines-editor.md).  
总入口见 [交互通则索引](./BestCheckout-interaction-guidelines.md).

适用面: Overview / Purchase flows / Checkout pages (列表与库) / Bundles / Subscriptions / Orders / Abandoned checkouts / Settings / Help / 连接与认证流.  
对照实现: `assets/theme.css`、`assets/shell.js`、`assets/nav.js`、各模块 `js/app.js` (非全屏装修器).

---

## 1. 总则

1. **一家后台, 一套壳.** 顶栏 + 侧栏由 shell 持久挂载; 模块只渲染 `#root`, 不各自再造导航.
2. **英文源文案, 中文 runtime overlay.** 菜单、按钮、toast、对话框、破坏性操作在源码写英文; 翻译靠 i18n.
3. **商家语言, 少实现细节.** 写商家要处理的结果 (如 In Shopify / Needs attention), 不默认暴露 shop_id、schema、webhook、队列名.
4. **同能力同交互.** 列表、弹窗、空态、删除确认在各模块对齐; 新页复用现有模式.
5. **主路径可点通.** 列表 → 详情 / 弹窗编辑 → 保存 / 取消 → 回列表; demo 店覆盖空态与异常态.

---

## 2. 壳与导航

| 原则 | 约定 |
|---|---|
| 布局 | 顶栏全宽 + 下方圆角内容卡 (侧栏 + `#root`) |
| 侧栏 | 一级菜单 + 可选子项; 当前路由高亮; 子组可折叠 |
| 设置 | 全屏设置壳 (左设置导航 + 右内容), 或侧栏子路由直达 |
| 店铺上下文 | 顶栏切换 demo 店; `?store=` 写入会话, hash 跳转后仍保持 |
| 连接态 | 未连接可跳出公共连接流; 进行中 / 失败态留在后台可见 |
| 返回 | 详情页用返回箭头或 Back, 回到列表或进入前的来源页 |

一级菜单只暴露 Checkout 增长相关能力, 不塞完整电商后台导航.

进入 Checkout / Thank you 全屏装修或主题编辑器后, 交互改看编辑器通则; 从编辑器 Exit 应回到本后台的页面库或来源路由.

---

## 3. 页面骨架

标准内容页自上而下:

1. **页头:** `page-title` (约 20px / 600) + 可选一句 muted 说明 + 右侧主操作
2. **筛选 / Tab 区** (如有): 与下方内容同卡或紧贴卡片顶
3. **主内容:** `panel` 卡片, 内用 `.tbl` 或卡片网格
4. **底栏:** 分页或 Total 汇总 (列表页)

间距: `#root` 约 `20px 24px 40px`; 卡片圆角约 12px, `card-pad` 约 16px.

**详情双栏:** 主列 + 约 275px 右侧信息轨 (`detail-wrap` / `detail-cols`). 订阅等编辑页的预览轨可 sticky, 仍属后台详情编辑, 不是全屏三栏装修器.

---

## 4. 视觉与控件尺度

| 元素 | 约定 |
|---|---|
| 主色 | `--brand: #0066e6`; 成功 / 警告 / 错误用 token |
| 字号 | 正文约 14px; 表格约 13.5px; muted 约 12–13px |
| 主按钮 | `.btn` 高约 32px; 筛选条内可 34px |
| 卡片内次要添加 | 可 28px (渠道卡添加等) |
| 输入框 | `.input` 高约 36px; focus 品牌色描边 |
| 圆角 | 控件约 8px; 面板约 12px |
| 图标按钮 | 约 32×32 |

色义: 绿 = 就绪 / 成功; 橙 = 进行中 / 需关注; 红 = 失败 / 危险; 灰 = 中性 / 未启用; 蓝 = 信息 / 产品标记.

---

## 5. 按钮与操作层级

| 层级 | 用法 | 样式 |
|---|---|---|
| Primary | 页内唯一主行动: Save / Update / Create / Connect | `.btn-primary` |
| Default | Cancel / 次要并行 / 打开外部 | `.btn-default` |
| Gray / quiet | Edit / Link / Copy 等工具操作 | `.btn-gray` 或弱按钮 |
| Danger | 确认后的删除等破坏键 | 红底或 `danger` 确认 |

- 一屏通常一个 Primary.
- 破坏性操作先确认; Cancel 不改数据.
- 忙碌态 disabled, 文案 Saving… / Syncing….
- 行内 Action 用短链或弱按钮, 窄列固定.

后台列表页的 Publish / Open editor 若只是跳进编辑器, 用 Default 或 Primary 之一保持页内单一主行动即可.

---

## 6. 列表与表格

默认: `.tbl` 全宽 + 行 hover + 有详情则行可点进详情.

| 原则 | 约定 |
|---|---|
| 表头 | 左对齐加粗; 数字列 `.num` 右对齐 |
| 单元格 | 约 `12px 16px`; 默认 nowrap, 长文 ellipsis |
| 筛选 | keyword / 时间 / 范围; 已生效条件用可清除 tag |
| Tab | 与搜索正交; 角标反映当前搜索下的数量 |
| 分页 | 底栏 Total + 分页; 全量展示时业务文档写明无分页 |
| Action | 不可删时不展示入口, 不灰掉误导 |

**配置类多行列表 (对齐员工列表):**

- 列: 主键 ID / Source / Name / 关键配置 / Action
- 不堆无关 Status、Pages, 除非本页有独立状态机
- Source 等用商家可读文案
- 普通长文: 列宽不够时 `...` 截断, hover 全文; 无值 `—`
- 已保存凭证: 列表外显用支付方式掩码 (前 4 位 + `····` + 后 4 位); hover 只提示已保存, 不展示原文
- 「当前生效」行置顶等排序写在业务 PRD; 交互保持稳定

**卡片网格** (Pages 库): pill Tab + 计数 + 卡片 (缩略图 / 名 / 状态 / Duplicate / Preview). 点进装修走编辑器通则.

---

## 7. 卡片与渠道块

| 形态 | 何时用 | 要点 |
|---|---|---|
| `panel` | 分区、表单组、KPI | 标题 + muted + 正文 |
| 渠道 / 能力卡 | Settings 多渠道 | 左说明、右状态 + 添加; 有数据才渲染表体 |
| 信息条 | 引导说明 | 蓝系弱提示, 不阻断 |
| Overview 面板 | 指标、趋势、待办 | 空数据说明「何时会出现」 |

空渠道: 无行不渲染空表头; 保留卡头与添加.

---

## 8. 空态 / 加载 / 异常

| 状态 | 交互 |
|---|---|
| 空列表 | 居中 muted 一句; 页头可保留主创建 |
| 空图表 / 动态 | 说明首笔后才出现, 不假造数据 |
| 加载 | 短文案 + 控件 disabled |
| 校验失败 | `has-error` / `is-invalid`, 文案贴字段 |
| 权限 / 连接不足 | 卡内告警 + 明确 CTA |
| Not detected | 卡头如实; 若允许则保留手动添加 |

---

## 9. 表单

1. Label 在上或沿用设置页 field 栈; 必填红色 `*`.
2. 只读: disabled / readonly 灰底, 值仍可见.
3. 凭证三处分开, 互不套用:
   - 暗提示: 写清要粘贴什么, 用完整说明; 不用 `sk_…` 或省略号代替密钥样例.
   - 输入内容: 输入框内展示正在输入或已保存的原文, 不用密码点, 也不用列表掩码.
   - 列表外显: 已保存凭证按第 6 节掩码; 无值 `—`.
4. 开关: 开启后再展开依赖字段.
5. 前缀 / 后缀 addon 与输入拼成一组.
6. 保存必检; 关键冲突可 Save + 失焦双检.
7. 成功: toast + 关弹窗或刷新列表; 失败阻断并说明.

---

## 10. 弹窗与确认

**标准 Modal:** 标题 + 可滚 body + Cancel + Primary; 宽约 420–560, 复杂 620–760; 遮罩 / X / Escape 关闭; input 上 Enter 可提交.

**Confirm:** 问句或短结论 + 后果; Danger Primary; Cancel 可退.

**冲突阻断:** 仅标题 / 说明 / 关闭; 无强制覆盖, 除非业务明文允许.

纯告知: 单按钮 (Got it / Close) + `hideCancel`.

切模板等编辑器三键门禁见编辑器通则, 不在后台普通表单使用.

---

## 11. Toast 与 Pill

**Toast:** 顶或底居中短句; 成功轻反馈; 不替代确认 / 错误弹窗.

**Pill:** `.pill` + 色义; 列表与详情枚举一致; 只读徽章不可点改状态, 改状态走编辑保存.

---

## 12. 设置页脏态

Settings 有未保存变更时, 可用顶部深色 unsaved bar: 说明文案 + Discard + Update.  
与全屏装修器顶栏 Dirty 分开, 不混用三栏编辑器布局.

---

## 13. 文案与 i18n

1. 英文源串稳定, 作词典 key.
2. 品牌名、第三方名、ID、域名 `i18n-skip`.
3. 切语言可 reload, 保留 hash.
4. 说明用完整句; 按钮用动词短语.
5. 控件名与状态枚举保持界面原文.

---

## 14. Demo 与原型元规则

1. 用店切换表达就绪度, 不多套平行页面.
2. Mock 形状对齐未来 API; 允许模拟异步 (验证不会假成真).
3. localStorage / sessionStorage 只作原型会话, 不当真源.
4. 新能力挂现有 IA; 不新增越界一级菜单.

---

## 15. 后台新页自检

- [ ] 复用 shell, 无第二套导航
- [ ] 页头 = title + 说明 + 单一主按钮
- [ ] 列表用 `.tbl` 或既有网格; 空态有一句说明
- [ ] 删除 / 替换经确认弹窗
- [ ] 表单必填、只读、错误可见
- [ ] 保存 toast; 失败阻断
- [ ] Pill 色义一致
- [ ] 英文源文案; 专有名 skip
- [ ] 不暴露内部实现字段
- [ ] 覆盖主路径、空态、一个异常 / 阻断态
